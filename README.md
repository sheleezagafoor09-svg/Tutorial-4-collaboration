# Tutorial 4B Collaboration Project
Tutorial 4B collaboration project with Laurell Wray (Wrayray) and Sheleeza Gafoor (sheleezagafoor09-svg)

## Purpose of the Repository
This repository was created to complete Tutorial 4 (Parts A and B). The purpose is to demonstrate Git and GitHub collaboration workflows, including creating a public repository, managing a README file, and executing an approved Pull Request.

## Steps Followed to Complete the Tutorial
1. Created a public repository on GitHub.
2. Added a collaborator to the repository settings.
3. Initialized the repository with a README.md file detailing the project purpose and collaborators.
4. Created a new branch to make edits.
5. Committed changes to the branch and opened a Pull Request (PR).
6. The collaborator reviewed and approved the Pull Request.
